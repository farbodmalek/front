# Girly Shop Frontend

فرانت‌اند فروشگاه آنلاین پوشاک دخترانه/زنانه با Next.js + TypeScript + Tailwind CSS.

## راه‌اندازی

```bash
npm install
npm run dev
```

## ساختار پروژه

- `src/app` — صفحات و روتینگ (App Router)
- `src/features` — منطق و کامپوننت‌های هر دامنه (product, cart, checkout, auth, wishlist, order)
- `src/components` — کامپوننت‌های عمومی (ui, layout)
- `src/lib` — کلاینت API، توابع کمکی، ثابت‌ها
- `src/types` — تایپ‌های مشترک بین فیچرها
